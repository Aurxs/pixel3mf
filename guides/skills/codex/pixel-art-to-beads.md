# Codex · 像素画转拼豆图纸

技能入口：[SKILL.md](../../../skills/codex/pixel-art-to-beads/SKILL.md)。

## 适合做什么

从已有像素画，或从文字、照片与角色参考生成像素画，制作带色号、坐标和用量统计的拼豆图纸。默认 MARD 221 色卡，支持自定义色卡。

技能目录保存提示词与色卡，程序使用本项目的 `tools/beads/`，不依赖其他技能或 Lumina。可以复用项目 Python 环境。生成新画和 AI 整理需要 Codex 生图工具；仅转换已有像素画不需要生图账户配置。

## 默认四个交付物

| 文件 | 内容 |
| --- | --- |
| `01_未压缩.png` | 裁掉外围空行空列、保留原像素的原向图纸 |
| `02_未压缩_镜像.png` | 同尺寸左右镜像图纸 |
| `03_压缩.png` | 适配 52×52 板子的原向图纸 |
| `04_压缩_镜像.png` | 同尺寸左右镜像图纸 |

镜像只翻转图案位置，标题和色号正常阅读。图面不写“正常版”和解释性说明。原尺寸与压缩尺寸分别统计用量；同尺寸的一对图纸用量相同。

## 示例指令

```text
使用 $pixel-art-to-beads，把这张已经抠好背景的像素画做成四张拼豆图纸。
保留未压缩原向和镜像，再输出适配 52×52 板子的原向和镜像。
保留外轮廓黑线、眼睛和嘴形。
```

```text
参考我家猫的照片生成像素画，再输出四张拼豆图纸。
压缩版适配 52×52，使用我的色卡，保留额头花纹与绿色眼睛。
```

可另行指定板子尺寸、最多用色数量、是否跳过 AI 整理。未指定颜色数时不强制限制为 15 色。

## 流程与结果

先得到可用的逻辑像素网格，然后分成两条支路：未压缩支路裁掉四周透明留白后排版，图纸网格与标注尺寸都贴合实际像素，内部空隙保留；压缩支路等比例缩小、保护外轮廓、由 AI 做局部整理，再用 Perfect Pixel 自动检测实际格数。黑线保护与全图选色分离，避免影响内部五官配色。

一个输出目录中，`delivery/` 只有四张交付 PNG；`work/` 保留原图、AI 输入输出、提示词、预览、PDF、CSV 和可编辑 JSON，`manifest.json` 记录两种尺寸与完整来源。已有最终像素稿跳过重新生图和不必要的网格识别。

源码目录与其他 Codex 技能一致：`SKILL.md`、`agents/`、`assets/`、`references/`。运行实现统一放在项目 `tools/beads/`；开发测试集中在项目 `tests/test_bead*.py`。
