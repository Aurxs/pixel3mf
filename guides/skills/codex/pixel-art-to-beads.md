# Codex · 像素画转拼豆图纸

技能入口：[SKILL.md](../../../skills/codex/pixel-art-to-beads/SKILL.md)。

## 适合做什么

从已有像素画，或从文字、照片与角色参考生成像素画，制作带色号、坐标和用量统计的拼豆图纸。默认 MARD 221 色卡，支持自定义色卡。

技能目录保存提示词与色卡，程序使用本项目的 `tools/beads/`，不依赖其他技能或 Lumina。可以复用项目 Python 环境。生成新画和 AI 整理需要 Codex 生图工具；仅转换已有像素画不需要生图账户配置。

## 按逻辑尺寸交付两张或四张

先裁掉透明外边，以实际逻辑格数判断（不是放大 PNG 像素）：宽高均 ≤52 时只交前两张，不补边、不压缩、不调用 AI；任一边 >52 时交四张。35×43、52×52 为两张，52×53、53×40 为四张。

| 文件 | 内容 |
| --- | --- |
| `01_未压缩.png` | 裁掉外围空行空列、保留原像素的原向图纸 |
| `02_未压缩_镜像.png` | 同尺寸左右镜像图纸 |
| `03_压缩.png` | 适配 52×52 板子的原向图纸 |
| `04_压缩_镜像.png` | 同尺寸左右镜像图纸 |

镜像只翻转图案位置，标题和色号正常阅读。图面不写“正常版”和解释性说明。原尺寸与压缩尺寸分别统计用量；同尺寸的一对图纸用量相同。

## 标题与小红书文案

图纸标题以中文名为主，日文名仅可括号补充，例如“中文名（日文名）”。优先使用用户的中文称呼；未知中文名先查正式来源，不自动翻译、音译或盲用日文。无法确认时询问中文称呼，或使用“拼豆作品”等中性中文标题。导出前确定 `--title`，程序不负责翻译。

用户要求小红书编辑文案时，标题、正文及话题标签均用纯中文，不夹带日文名或其他外语。此规则不涉及自动发布或重生成图片。

## 示例指令

```text
使用 $pixel-art-to-beads，把这张已经抠好背景的像素画按逻辑尺寸做成两张或四张拼豆图纸。
保留未压缩原向和镜像，仅超限时再输出适配 52×52 板子的原向和镜像。
保留外轮廓黑线、眼睛和嘴形。
```

```text
参考我家猫的照片生成像素画，再按逻辑尺寸输出两张或四张拼豆图纸。
压缩版适配 52×52，使用我的色卡，保留额头花纹与绿色眼睛。
```

可另行指定板子尺寸、最多用色数量、是否跳过 AI 整理。未指定颜色数时优先约 18 色，自然效果优先，不硬限、不凑色，保留眼睛和嘴等少量关键颜色。

## 流程与结果

先得到可用的逻辑像素网格，然后按是否超限决定支路：未压缩支路裁掉四周透明留白后排版，图纸网格与标注尺寸都贴合实际像素，内部空隙保留；仅超限时，压缩支路等比例缩小、保护外轮廓、由 AI 做局部整理，再用 Perfect Pixel 自动检测实际格数。黑线保护与全图选色分离，避免影响内部五官配色。

一个输出目录中，`delivery/` 只有所需两张或四张交付 PNG；`work/` 保留原图、AI 输入输出、提示词、预览、PDF、CSV 和可编辑 JSON，`manifest.json` 记录逻辑尺寸、是否需要压缩、预期交付数量与完整来源。已有最终像素稿跳过重新生图和不必要的网格识别。

源码目录与其他 Codex 技能一致：`SKILL.md`、`agents/`、`assets/`、`references/`。运行实现统一放在项目 `tools/beads/`；开发测试集中在项目 `tests/test_bead*.py`。
