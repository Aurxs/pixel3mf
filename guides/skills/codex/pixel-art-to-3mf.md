# Codex · 动漫角色像素画转 3MF

技能入口：[SKILL.md](../../../skills/codex/pixel-art-to-3mf-skill/SKILL.md)。技能名是 `pixel-art-to-3mf`，文件夹名保留 `pixel-art-to-3mf-skill`。

## 适合做什么

适合沿用项目原有动漫角色风格的粗像素人物任务，包括文字生图、参考图辅助生成，以及已有角色像素图转换。它保留了角色上半身、眼睛、姿态与源图检查等专用规则；宠物、物品、全身通用构图优先使用[通用技能](general-pixel-art-to-3mf.md)。

## 准备信息

提供角色名与版本、需要保留的服饰 / 发型 / 道具、希望的姿态，以及参考图。对于可识别角色的生成或创作性编辑，技能会先查官方来源并保存研究记录。直接转换已有图片不需要重新生成。

## 示例指令

```text
请读取 skills/codex/pixel-art-to-3mf-skill/SKILL.md。
为芙莉莲制作自然上半身粗像素画，先查官方角色资料，
保留标志性发型、服饰和眼睛特征，按技能要求完成预检、
背景处理、Perfect Pixel 整理，再导出 2x2 与 3x3 两份 3MF。
```

```text
请使用 pixel-art-to-3mf，直接转换附件中的已有动漫像素图，
不要重画。保留原图和中间预览；遇到网格或遮罩问题时指出原因。
```

## 流程与产物

按技能完成资料核对、生成 / 接受源图、源图网格检查、语义背景处理、网格整理、叠色预览与双尺寸导出。生图原件要求纯白、不透明背景；用户提交的已有透明图片走相应 Alpha 处理路径。

主要输出在 `output/<时间戳>_<角色名>/`：源图、遮罩预览、整理后的逻辑图、两个 Lumina 预览、`08_*_2x2.3mf`、`08_*_3x3.3mf` 与 `manifest.json`。3x3 成品已经完成 XY 补偿，不需要在切片器重复放大。

## 使用边界

原总入口的网格检测规则可能拒绝不符合要求的输入。不要靠任意缩放、固定网格强压或忽略遮罩歧义来让它通过。Windows 用户可以用双击入口处理符合原流水线要求的已有图片；如需生图或角色研究，仍须由 AI 执行技能。

像素 3MF 默认写入 A1 mini 0.4 喷嘴配置并使用红蓝黄白 LUT，切片前核对自己的设备与耗材。
